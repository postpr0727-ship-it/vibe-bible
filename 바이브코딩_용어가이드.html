💡 바이브 코딩 프롬프트 패턴 (Prompt Pattern)

AI에게 일을 더 잘 시키기 위한 마법의 문장 구조입니다.

1. 역할 부여 (Role)
AI에게 전문가 페르소나를 입혀 결과물 품질 향상
🗣️ 사용 예시 "너는 10년차 시니어 프론트엔드 개발자야.
모바일 최적화와 웹 접근성을 최우선으로 고려해서 코드를 짜줘."
2. 단계별 유도 (Chain of Thought)
한 번에 말고 순서대로 생각하게 하여 오류 감소
🗣️ 사용 예시 "다음 순서로 진행해줘:
1. 먼저 HTML 구조를 잡고
2. CSS 변수로 컬러 시스템을 정의하고
3. 마지막에 레이아웃 스타일을 적용해줘"
3. 예시 제공 (Few-shot)
원하는 스타일의 예시 코드를 줘서 방향성 고정
🗣️ 사용 예시 "아래 코드 스타일처럼 작성해줘:
(내가 좋아하는 깔끔한 코드 예시 붙여넣기)
이 스타일을 유지하면서 로그인 페이지를 만들어줘."
